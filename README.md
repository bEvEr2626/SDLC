## CakeCalculator

**Автор:** Липский А. В.

**Дисциплина:** Жизненный цикл разработки программного обеспечения

**Название проекта:** «Калькулятор тортиков»

### Описание проекта

CakeCalculator— настольное приложение, разрабатываемое
на языке C# с использованием AvaloniaUI.
Приложение рассчитывает количество сигарет, которые человек выкуривает в день, и в соответствии со всеми параметрами высчитывает, сколько можно было купить за эту стоимость тортиков и апельсинов.
В проекте планируется использовать архитектурный шаблон MVC.
